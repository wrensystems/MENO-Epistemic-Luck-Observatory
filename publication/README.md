# MENO publication artifacts

- `report/MENO_Research_Report.pdf`: final research manuscript, seven pages,
  including five main-text pages and two pages of references and appendices.
- `report/MENO_Research_Report.docx`: editable manuscript source, adapted from the
  official Apart Research template.
- `report/MENO_Research_Report.md`: content mirror for source review.
- `slides/MENO_Presentation.pptx`: twelve-slide editable presentation, with native
  tables and chart plus speaker notes for approximately four to five minutes.
- `slides/MENO_Presentation.pdf`: searchable presentation PDF.

The study is an exploratory ceiling observation, not evidence of equivalence or
general audit ineffectiveness. Public branding is MENO: Epistemic Luck Observatory.
Necessary internal module identifiers remain for archival compatibility.

The files report historical live results but do not contain the original raw
response archive. See `data/README.md` and the manuscript's Code and data section.
The package's creation is not submission to Apart Research or publication of a
GitHub repository. It contains no private Git history, credentials or unrelated
participant study infrastructure. The author is responsible for final review.
